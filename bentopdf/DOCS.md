# BentoPDF

Tutti gli strumenti PDF nel browser: unire, dividere, ruotare, comprimere, convertire, firmare, OCR e altri. I file vengono lavorati **nel tuo browser**: il server di Home Assistant serve solo la pagina e non vede i documenti.

## Uso
Avvia l'add-on e apri `http://homeassistant.local:8095/` (o «Apri interfaccia web»). La porta si cambia nella scheda Rete dell'add-on.
